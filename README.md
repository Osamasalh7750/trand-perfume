# 🌸 متجر "عطورات اترند" - ATRAND LUXURY PERFUMES

مشروع متجر إلكتروني فاخر مخصص لعرض وبيع العطورات، مبني بتصميم عصري راقٍ (Luxury Gold & Noir Theme)، ومصمم ليعمل **مباشرة كصفحة ثابتة (Static Website)** بالنقر المزدوج على ملف `index.html` دون الحاجة لتشغيل أي سيرفر خلفي.

---

## ✨ المميزات الرئيسية للمتجر

1. **تشغيل مباشر بالمتصفح (Double Click Execution)**:
   - يمكنك فتح ملف `index.html` بالنقر المزدوج عليه في أي متصفح (Chrome, Edge, Firefox, Safari).
   - التنقل السلس بين الواجهة الرئيسية، نافذة تفاصيل العطر، سلة المشتريات، ولوحة إدارة المتجر دون أي إعادة تحميل للصفحة أو تعقيدات.

2. **متجر خالي من البيانات الأولية (Clean Slate)**:
   - يبدأ المتجر نظيفاً وجاهزاً دون أي عطور تجريبية سابقة بناءً على طلبك.
   - عند فتح المتجر للمرة الأولى، تظهر رسالة ترحيبية أنيقة تُتيح لمدير المتجر الدخول فوراً وإضافة العطور الحقيقية.

3. **لوحة تحكم وإدارة المتجر (Admin Dashboard)**:
   - محمية بنظام تسجيل دخول مستقل لا يتاح للمستخدم العادي:
     - **البريد الإلكتروني:** `admin@ovrax.com`
     - **كلمة المرور:** `Ovrax123`
   - إمكانية إضافة عطور جديدة، تعديل بياناتها، أو حذفها بنقرة زر.
   - رفع صور العطور مع ميزة السحب والإفلات (Drag & Drop) ومعاينة فورية.
   - حفظ كافة مواصفات العطر:
     - اسم العطر.
     - تصنيف العطر (رجالي، نسائي، للجنسين، شرقي وعود).
     - السعر الأساسي بالريال السعودي.
     - نسبة الخصم % وسعر التخفيض المحسوب آلياً.
     - نص العرض الترويجي الخاص (إن وجد).
     - حجم العبوة (مل).
     - الهرم العطري الكامل (قمة العطر، قلب العطر، قاعدة العطر).
     - الوصف التسويقي للعطر.

4. **نظام تخزين البيانات وتصدير/استيراد JSON**:
   - يتم حفظ العطور والصور فورياً في المتصفح عبر `localStorage` بصيغة بيانات سريعة (Data URL)، مما يضمن ظهور المنتجات وتحديثها فوراً دون الحاجة لقاعدة بيانات خارجية.
   - يوجد في لوحة الإدارة زر **"تصدير وتحميل products.json"** يتيح لك تنزيل ملف نصي JSON يحتوي على كافة المنتجات وحفظه داخل مجلد `data/`.
   - يوجد زر **"استيراد ملف products.json"** لتحميل بيانات العطورات في أي وقت واستعادتها.

5. **نافذة تفاصيل العطر المنبثقة (Product Modal)**:
   - بمجرد نقر الزائر على بطاقة أي عطر، تبرز نافذة تفاعلية أنيقة تعرض:
     - صورة العطر المكبرة بجودة عالية.
     - شارات الخصم والعرض الخاص إن وجدا.
     - السعر قبل وبعد الخصم.
     - مكونات الهرم العطري بالتفصيل.
     - محدد الكمية وزر الإضافة إلى السلة.

6. **سلة المشتريات والتحويل للشراء عبر الواتساب**:
   - سلة مشتريات جانبية (Drawer) تعرض المنتجات، صورها، وأسعارها وإمكانية تعديل الكميات أو الحذف.
   - حساب فوري للمجموع، الخصومات الموفرة، والمبلغ النهائي المطلوب.
   - عند الضغط على **"إتمام الطلب عبر الواتساب"**، تفتح نافذة إدخال بيانات العميل (الاسم الكريم، المدينة وعنوان التوصيل، الملاحظات).
   - يتم إنشاء رسالة واتساب عربية منسقة بدقة واحترافية، والتحويل المباشر للدردشة مع رقم المتجر:
     👉 **`+966568009474`**
